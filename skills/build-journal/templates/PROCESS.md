# Process log

Append short entries at chosen checkpoints. Preserve earlier entries; append a correction when evidence changes a claim.

Use `## <UTC timestamp> — <kind>` for each entry. Kinds: observation, hypothesis, experiment, result, change, blocker, next. In the entry text, identify the human or AI author, whether the account is contemporaneous or retrospective, the source, and any uncertainty. If a helper supplies only the timestamp and kind, put these details in the supplied text.

Record the hypothesis before the experiment when available, what was actually attempted, what happened, and what changed as a result. Label a reconstructed hypothesis retrospective. A suggested command or planned test is not an executed experiment. If a needed detail is missing, mark it unfinished rather than guessing.
